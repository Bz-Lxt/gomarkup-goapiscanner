# 原始需求 (Original Prompt)

> 冻结时间：2026-08-23 22:50 (GMT+8)
> 命令：`/pm`

帮我用Go语言实现一个全栈云原生自动化 API 缺陷扫描、渗透漏洞利用与合规报告平台

**实用价值**：企业开发完大量 HTTP/RPC 接口后，上线前必须通过该系统进行全自动的安全漏洞扫描，检查是否存在 SQL 注入、XSS、未授权访问等漏洞。

**前端页面 (Vue 3 + 全生命周期缺陷树 + 漏洞实时打印流)**：
- 安全扫描控制台：用户输入基础 URL 或上传 Swagger 接口 JSON 文件。
- 漏洞监控看板：采用树级结构和高亮标签（严重、高危、中危）实时展示扫描出的安全隐患。
- 安全合规报告预览页：自动渲染生成一份精美的 PDF 级别合规报告，包含代码修复建议。

**Go 后端核心实现**：
- 自制高性能网络发包并发引擎：解析 Swagger 后，利用 Go 的 net/http 极快地生成成千上万个带"恶意载荷（Payload）"的变异测试请求。
- 漏洞指纹匹配器（Fingerprint Matcher）：手写解析算法。通过检查后端接口返回的 HTTP 状态码、响应头（Headers）以及特定 Body 字符串，精准判定目标是否存在漏洞（如时序盲注的延迟特征），同时防止重入和死锁。

**文件数与代码量**：约 35+ 个 Go 文件，代码量 6500 - 9000 行。
